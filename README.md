# صَنْعَة San3a: الموقع (نسخة 2)

موقع static من غير أي build وقت الرفع، بـ 4 لغات (عربي، English، Deutsch، Русский)، ووضع نهاري وليلي.

```
san3a/
├── site/      ← ده اللي بيترفع على Vercel أو GitHub Pages
└── source/    ← مولّد الصفحات (Python)، للتعديل على النصوص
```

## اللغات
| اللغة | المسار |
|---|---|
| العربية (الأساسية) | `/` |
| English | `/en/` |
| Deutsch | `/de/` |
| Русский | `/ru/` |

اختيار اللغة موجود فوق في الشريط العلوي، وبيوديك لنفس الصفحة باللغة التانية.

## الوضع الليلي
فيه زرار في الشريط العلوي، والموقع بيفتكر اختيار الزائر. لو الزائر ما اختارش، الموقع بيمشي على إعدادات جهازه.

## الإعدادات: ملف واحد
كل الإعدادات في `site/assets/js/config.js`:

- `whatsappNumber`: رقم الواتساب بالصيغة الدولية، مثال `201001234567`. طول ما هو فاضي، أزرار الواتساب بتظهر «قريبًا».
- `formEndpoint`: رابط استقبال الفورمز (Google Apps Script أو Formspree أو أي API). طول ما هو فاضي، الفورمز شغالة **وضع تجريبي**: الطلب بيتحفظ على جهاز اللي بعته بس، ومش بيوصلك.
- `phone` و`email` و`workingHours` و`social`: بتظهر في الموقع أول ما تملاها.

كل فورم بيتبعت كـ `multipart/form-data`، ومعاه الحقول دي:
- `form_type`: نوع الفورم، وقيمته واحدة من `service_request` أو `b2b_inquiry` أو `technician_signup` أو `contact_message`.
- `lang`: لغة الصفحة اللي اتبعت منها الفورم.
- `photo_1` لحد `photo_5`: صور فورم طلب الفني.

## تعديل النصوص
كل النصوص باللغات الأربعة موجودة في `source/content.py`. بعد ما تعدّل، شغّل:

```bash
python3 source/build.py
```

الأمر ده بيعيد توليد كل صفحات `site/`. محتاج Python 3.12 أو أحدث، ومن غير أي مكتبات إضافية.

لما يبقى عندك دومين، حطه في `SITE_URL` في أول `source/build.py` وشغّله تاني. كده هيتضاف `canonical` و`hreflang` لكل صفحة، ودي مهمة لمحركات البحث مع تعدد اللغات.

## الرفع
**Vercel:** ارفع فولدر `site` كمشروع (Framework Preset: **Other**)، وسيب Build Command و Output Directory فاضيين.

**GitHub Pages:** ارفع محتوى فولدر `site` على جذر الـ repo، وبعدين Settings ← Pages ← `main` / `root`. ملف `.nojekyll` موجود بالفعل.

## الحركة والأنيميشن
- لو جهاز الزائر مفعّل عليه «تقليل الحركة» (Reduce motion)، كل الأنيميشن بيقف تلقائي.
- شريط الخدمات المتحرك عليه زرار إيقاف.
